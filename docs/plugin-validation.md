# 插件验证范围

插件与项目版本为 1.7.0；HTTP API v4、1,424 条词库及用户数据结构保持兼容；种子版本为 5，迁移先备份并保留个人改删。

## 自动验证

运行 `pwsh -NoProfile -File scripts/package-plugin.ps1`：

1. 从主项目源码生成插件运行副本，将网页共用执行规则嵌入 Skill，再逐文件比较内容。
2. 生成 ZIP 并解压到临时目录，以解压版作为独立 CLI 的测试来源。
3. 运行 44 项 Node 内置测试，包含资料分类、来源与长度、默认 16 条、旧 ID 兼容、迁移与用户改删、HTTP/CLI/MCP 同源、抽取约束和完整提示词检查。文本输出保留全部名称与说明，省略内部 ID、抽取元数据和参考链接；强度未选时不展开，必须保留独立生效。
4. 检查所有插件文件前后 SHA-256，确认执行过程没有写入安装目录；子进程设置超时，测试服务使用临时数据并关闭。
5. 检查成功后才替换交付 ZIP，清理临时目录，打印 `DONE`。

验证覆盖默认八维各 2 条共 16 条、显式随机 2–3 条、全部主题冷暖范围、独立特色 1–5 条、锁定与单维重抽、显式冲突与自由模式、失效 ID、UTF-8/BOM/超大文件、工作台的个人词库与编辑词条、HTTP/MCP 查询一致性、共享历史、保存失败、快照稳定及连接中断的未知保存状态。原有测试继续覆盖空库、无组合、搜索上限、迁移和重启。

发布时另用 Codex 的 plugin-creator 校验器检查插件清单与资源，用 skill-creator 校验器检查 Skill 格式。插件无自动 MCP 配置、没有个人数据或本机用户路径，资源路径均位于插件内部。

## Skill 执行边界走读

以下是对实际 Skill 指令的场景走读，用于检查交付范围、落实标准和冲突决策；不是对多个模型的成功率评测，也不保证每次设计都达到相同审美结果。自动测试确认规则被完整嵌入网页提示词与 Skill，不能证明接收模型一定遵循。

| 用户请求 | 应采取的路径 | 已核对的边界 |
| --- | --- | --- |
| “按结构重构当前前端，保留业务功能” | 读取项目及现状 → 使用整组词条 → 重组信息、导航与布局 → 实现并对照原页面检查。 | 用户已经指定强度，直接执行；保留功能能力与数据含义，不自动保留原有侧栏和卡片组合。 |
| “优化这个页面”，未选择重构强度 | 按原始任务与明确约束执行，不额外套用四档规则。 | 网页不复制强度栏目与档位规则；Skill 不强制选择档位，只有任务范围确有必要澄清时才询问。 |
| “只给三个方案，不改代码” | 按需查询与抽取，为三个方向分别给出配色、布局、字阶与应用区域。 | 只输出设计简报，代码不修改；不因 Skill 的默认实现工作流越过用户范围。 |
| “必须保留品牌蓝 #1246A0、现有字体与 React” | 在品牌、技术及保留范围内编排；已选择强度时同时遵循，词条确实无法兼容时主动询问。 | 明确的品牌、技术与局部范围保留，不能用随机结果覆盖或静默丢弃冲突项。 |
| “液态金属会影响清晰，所以删掉” | 尝试把效果放在选中徽记或限定区域，保留可辨识的反射与流体形态。 | 清晰度是实现约束，不能单独作为删除理由；只放“液态金属”文字不合格。 |
| “可拖拽画布只放一个拖拽图标” | 验证真实拖动改变视图或对象位置，并提供等效键盘操作。 | 图标、文案、CSS 类名都不能作为实际交互完成证据。 |
| “多个主导风格同时出现” | 分配到不同区域、层级或状态，逐条保留可识别表达。 | 可以兼容时继续实现，不仅因为难做就要求用户删词。 |
| “全站只能黑白，又要求全站饱和多彩” | 说明同一全局范围的具体冲突与可选调整方案，主动询问用户。 | 未答复不表示同意；保留要求、继续无关工作，不擅自删除或宣称全部完成。 |
| “将术语变成游戏名称即可” | 保留游戏内容含义，落实真实的视觉、排版、材质或行为。 | 出现在产品文案里本身不算落实；排版类词条要改变实际字形、字阶或编排。 |
| “主导风格只出现在角落贴纸里” | 对照指定作用范围和主要区域，调整构图、视觉语言或核心交互，核查实际主导地位。 | 普通词条抢占焦点时调整层级，不只在交付文字中声称主导。 |
| “错误详情页中记录数量比错误原因更醒目” | 明确主要任务，对照实际视觉重心，调整位置、强度和层级，同时保留词条表达。 | 可辨识的术语表达还须服务页面的信息和操作重点。 |

以上路径均按需查询摘要与少量术语，不把完整词库注入上下文。鼠标、持续动效及三维线索需要对应触控、静态或减少动态替代。纯后端及非视觉修复不进入该 Skill。

## 网页行为验证

浏览器回归覆盖三个取样入口、默认已有术语、正文与出处阅读、个人混选、旧范围提示及当前结果保留；也覆盖三档维度权重、词条继承与单独覆盖、恢复跟随、单维重抽保留其他项、新词继承、一键恢复普通、完整提示词与纯词条及原始 JSON、剪贴板失败回退、记录页不带当前草稿、收藏和历史不受影响、任务与权重不写浏览器存储、刷新清空、键盘操作及 320–1440 像素布局。

使用 41 条实际抽取结果检查完整提示词、纯词条和记录页复制：保留全部名称与说明、有效权重及设计数值，省略抽取元数据与内部 ID；原始 JSON 保持完整。自动复制不可用时，手动复制框内容与预览一致。

四档按钮与必须保留输入另验：默认不选档、切换与清除、仅展开当前档位、逐词核查规则、复制反馈、历史和收藏不受影响、刷新清空，以及宽屏和窄屏键盘操作。页面与工具默认前八维各 2 条，旧有显式数量和随机选择继续有效。

预览展示一组示例词条与临时权重，收藏仍只有原始词条快照。网页没有新增聊天服务或自动调用模型；冲突询问由使用提示词的 agent 执行。

## 未自动执行的安装操作

验证不添加当前机器的 marketplace、不安装全局插件、不修改 MCP 配置、不启动常驻服务。安装说明中的 marketplace 与 MCP 命令已按当前 Codex CLI 帮助核对；清单通过格式与资源校验，但没有宣称已在用户的插件页完成安装。需要用户按安装说明自行添加来源和安装。
