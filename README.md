# 形意词库 · FormLex

**一键抽取设计灵感，让 agent 的前端少一点「AI 味」。**

以形启意，组合下一次设计。FormLex 是面向设计师与 coding agent 的设计灵感词库：收录 **1,424 条设计线索**，覆盖 **8 个常规维度 + 可选的网站特色**，每条都附有具体的前端应用说明。选一份主题词库、自己挑选术语，或从全部词库抽取，为页面找到更鲜明的视觉方向。

[快速开始](#快速开始) · [主题与自选词库](#主题与自选词库) · [给 agent 的提示词](#给-agent-的提示词) · [可选 MCP](docs/mcp.md) · [HTTP API](docs/api.md)

## 为什么术语能帮上忙

“高级、现代、有设计感”留下了很大的解释空间。专业术语可以把设计意图落到明确的视觉关系上，让 agent 有依据地决定网格、比例、色彩、字体和细节。

FormLex 为每个术语配上应用说明，把美术语言接到前端实现中。例如：

| 设计线索 | 可以交给 agent 的具体决策 |
| --- | --- |
| 瑞士国际主义 | 建立严谨网格、非对称编排与无衬线字体系，用对齐组织信息。 |
| 浮世绘平面性 | 用轮廓勾线、平涂色面和大胆裁切处理主视觉，形成鲜明的平面关系。 |
| 邻近色配色 | 在相邻色相中建立色板，再通过明度差区分背景、内容和强调区域。 |
| 现代衬线 Didone | 用高笔画对比的大标题建立视觉焦点，正文选择更适合阅读的字形。 |
| 透明罩染 Glazing | 叠加薄透明色层表现材料深度，让底色参与表面质感。 |
| 预备动作 Anticipation | 在主要变化前加入短暂的方向或尺度提示，让动作更容易理解。 |

这些线索提供了**可执行的约束、可组合的差异和可讨论的设计依据**。你可以明确地要求“保留编辑式排版，把材质换成暖纸”，逐步收敛到适合内容的界面。

## 为前端「去 AI 味」的工作流

1. **抽取方向**：选择词库与维度，按需设置冷暖倾向、开启网站特色，再点击“抽取一组灵感”。常规维度默认获得 2–3 条术语及说明；特色独立取 1 条。
2. **交给 agent**：点击“复制文本”，连同页面需求和下方提示词一起发送，让 agent 将术语落实到界面。
3. **保留与调整**：锁定喜欢的维度，只重抽需要改变的部分；根据实际页面继续调整配色、比例与细节。

FormLex 提供设计输入，页面由你使用的 agent 构建。术语组合用于启发主次和应用范围：确定一个主导方向，再让其余线索服务于局部元素，避免把所有风格平均铺满页面。

## 项目优势

- **从美术语汇中寻找差异**：1,424 条词条涵盖艺术流派、构成、色彩关系、排印、材料与运动规律；哥特式、文人山水、朋克剪贴、蒸汽波和观念艺术带来截然不同的出发点。
- **给网站一个记忆点**：150 条可选特色描述完整的页面体验，从追逐鼠标的彩色灯光、霓虹渐变，到滚动叙事、可拖拽画布和三维展厅，并附触控、静态或减少动态的替代建议。
- **配色有明确方向**：冷、暖严格按人工标注筛选，10 个主题各有至少 5 条冷色与 5 条暖色配色，随机模式保留中性和混合色彩的探索空间。
- **每个词都有落地说明**：将抽象概念转化为可以用于布局、视觉或交互的建议，减少反复解释设计意图的成本。
- **随机探索，也能精确控制**：每维度可选固定 1–5 条或随机 2–3 条，支持维度选择、整组锁定与单维重抽，保留有效方向，持续尝试新组合。
- **人和 agent 共用一份词库**：网页可直接操作，HTTP API 可供本机 agent 调用，也可按需配置 MCP 工具；中文文本与结构化 JSON 都能复制使用。
- **自己决定抽取范围**：10 份主题词库均覆盖八个维度，也可搜索、勾选词条保存为个人词库，减少抽到无关方向的次数。
- **沉淀自己的设计语言**：词条、说明与互斥关系均可编辑；喜欢的组合可以收藏，最近 100 次成功抽取自动保留快照。
- **本机运行，零额外依赖**：使用 Node.js 原生 HTTP 服务与 HTML、CSS、JavaScript，无需 API Key。词库和记录保存在本机 JSON 文件中，抽取过程不调用模型。

## 网站特色与冷暖配色

**特色默认关闭。** 打开“添加特色”，选择独立的 1–5 条（默认 1 条）。它不受常规维度数量或所选词库影响；取消前八维的勾选，可只抽特色。特色同样可以锁定整组、单项重抽、复制和收藏。关闭会解除特色锁定，之后的抽取不再包含它；当前结果与历史快照保留。

**色彩倾向默认为随机。** 选择“冷色调”或“暖色调”，只从当前词库中相应分类的色彩词条抽取；自由模式也遵守这一筛选。中性、混合与未分类只参与随机，不根据词条名称猜测冷暖。词库编辑器可维护这五种分类。

筛选后候选不足，或锁定的色彩不符合所选色温，会说明原因并保留当前结果。可以自行减少数量、解除锁定或修改条件，工具不会跨词库补齐。界面记住特色开关、特色数量、色温、常规数量和词库选择；条件更改在下次抽取生效。锁定组始终保留实际词条数，优先于新的数量设置。

## 给 agent 的提示词

将下面的模板与抽取结果一起发送，替换其中的项目需求即可：

```text
请为以下项目构建或重构前端：
[页面用途、目标用户、核心内容、技术栈与现有约束]

使用后面的 FormLex 设计灵感组合：
1. 根据项目内容确定一个主导设计方向，说明其余术语适合应用在哪些区域。
2. 将术语落实为布局、间距、配色、字阶、形状、材质与交互反馈的具体选择。
3. 让视觉层级围绕内容和主要操作展开，控制装饰的使用范围。
4. 同时处理窄屏布局、文字可读性、键盘操作和减少动态偏好。
5. 完成实现后，检查实际页面，并简要说明采用了哪些线索、如何落地。

设计灵感组合：
[粘贴 FormLex 复制的文本]
```

已有满意的页面时，可以只抽取色彩、排版或材质，给局部改版提供方向；搭建新页面时，则可以从完整的八维组合开始。

## 快速开始

需要 **Node.js 22 或更新版本**。

```sh
git clone https://github.com/Inderwish/formlex.git
cd formlex
node server.mjs
```

打开 <http://127.0.0.1:3000>。无需执行 `npm install`。按 Ctrl+C 停止服务。

Windows 用户也可以双击项目目录中的 **`启动灵感采样.bat`**，服务就绪后会自动打开浏览器。保留终端窗口即可持续使用，关闭窗口则停止服务。

指定端口或数据位置：

```sh
node server.mjs --port 3001
node server.mjs --data-file ./my-data/state.json
```

也支持 `PORT`、`DATA_FILE` 环境变量，命令行参数优先。服务只监听 `127.0.0.1`；不要让多个实例同时使用同一个数据文件。

## 工作台功能

| 功能 | 用法 |
| --- | --- |
| 协调模式 | 排除词库中显式配置的互斥关系，覆盖同维度与跨维度组合；任一方向声明互斥即生效。 |
| 自由模式 | 在所选词库与色温范围内独立随机，允许显式互斥的组合。 |
| 自定义数量 | 常规维度固定抽取 1、2、3、4 或 5 条，或保持默认随机 2–3 条；数量更改只影响未锁定维度。 |
| 锁定与重抽 | 锁定会保留该维度整组词条及顺序；单维重抽保持其余结果不变。 |
| 全览与单维聚焦 | 调整查看范围，复制和收藏始终保留完整组合。 |
| 词库管理 | 按维度与色温筛选、搜索、新增、编辑和删除词条，维护互斥关系；选择特色维度进入独立词池。 |
| 复制与收藏 | 复制中文文本或 JSON；剪贴板不可用时提供手动复制文本框。 |
| 收藏与历史 | 每次打开页面会自动抽取一组；网页和 HTTP 抽取均进入历史。收藏独立保存，词条后续修改不会改变已有快照。 |

协调模式只检查显式互斥，不做模型语义判断。候选不足、锁定冲突或搜索达到上限时会提示原因并保留当前结果，可调整条件后再抽取。

## 让 agent 直接调用

**MCP 是可选功能。** 直接使用网页或 HTTP API 无需配置 MCP，也不会自动启动 MCP 进程。

需要工具调用时，按照 [MCP 接入说明](docs/mcp.md) 配置 stdio 连接程序，即可使用 `list_design_libraries`、`search_design_keywords`、`draw_design_inspiration`。MCP 连接已经启动的本机服务，抽取结果与网页共用历史，支持主题与个人词库、独立特色、冷暖筛选、锁定和单维重抽。

启动服务后，具备本机 HTTP 访问能力的 agent 可以直接读取词库或抽取灵感。在 Windows 的 **pwsh** 中也可以调用：

```sh
curl.exe http://127.0.0.1:3000/api/catalog
curl.exe --json '{"mode":"coordinated"}' http://127.0.0.1:3000/api/draw
curl.exe --json '{"dimensions":["color","type","material"],"mode":"free","countPerDimension":2}' http://127.0.0.1:3000/api/draw
curl.exe --json '{"libraryId":"digital","mode":"free","dimensions":["style","color","feature"],"colorTemperature":"cool","featureCount":1,"countPerDimension":2}' http://127.0.0.1:3000/api/draw
curl.exe --json '{"dimensions":["feature"],"featureCount":3}' http://127.0.0.1:3000/api/draw
```

抽取响应包含记录 ID、时间、模式、词条及可复制文本。网页与 API 共用同一套词库、抽取规则和记录。

完整的请求参数、锁定与重抽示例、词条编辑接口及错误说明见 [HTTP API 文档](docs/api.md)。

## 数据与开发

- `seed.mjs`、`seed-extra.mjs`：原有 1,200 条术语、维度定义与显式互斥规则。
- `seed-palette.mjs`：逐条人工色温分类与 74 条补充配色；`seed-features.mjs`：150 条网站特色。
- `seed-membership.json`：按词条 ID 维护的内置词库归属清单。
- `libraries.mjs`：主题词库定义；`mcp.mjs`：独立的可选 MCP 连接程序。
- `public/`：网页界面；`server.mjs`：本机 HTTP 服务。
- `core.mjs`：抽取、互斥规则和本地保存逻辑。
- `data/state.json`：首次运行时创建，保存词条、个人词库、历史和收藏。

数据文件使用 UTF-8，通过临时文件替换保存。保存失败会报告错误；遇到损坏的数据文件时保留原文件，不会重置为初始词库。关闭服务后备份整个 `data/` 目录，即可保留个人数据；该目录已加入 Git 忽略规则。

已有数据在首次使用新词库时会先备份，再追加新范围的内置词条。原有修改、删除、个人词库、历史和收藏会保留；完成合并后，再次启动不会恢复你已经删除的词条。未改写的内置色彩会补入人工分类；用户改写或自定义且未分类的色彩保留为“未分类”。备份位于数据文件旁的 `.before-v4.bak`，种子版本为 4；旧快照缺少新字段仍可读取。升级源码后请关闭旧服务，再重新运行启动脚本。

运行测试：

```sh
node --test tests.test.mjs mcp.test.mjs
```

测试覆盖 1,424 条词库完整性、主题冷暖数量、独立特色、自选范围、严格色温、抽取约束、锁定重抽、输入校验、HTTP 接口、数据迁移、持久化、快照、同源限制、保存失败及真实 stdio MCP 调用。测试使用临时数据，完成后关闭测试服务和 MCP 子进程并清理，成功时打印 `DONE`。

术语参考：[Getty：艺术与建筑叙词表](https://www.getty.edu/vow/AATSearchPage.jsp)、[MoMA：艺术术语](https://www.moma.org/collection/terms/)、[Adobe：字偶距、字距与行距](https://helpx.adobe.com/ca/illustrator/using/line-character-spacing.html)。词条中的前端应用说明为本项目撰写。
