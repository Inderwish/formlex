# 形意词库 · FormLex

**一键抽取设计灵感，让 agent 的前端少一点「AI 味」。**

以形启意，组合下一次设计。FormLex 是面向设计师与 coding agent 的设计灵感词库：收录 **400 条美术与设计术语**，覆盖 **8 个设计维度**，每条都附有具体的前端应用说明。抽取一组、复制给 agent，为页面找到更鲜明的视觉方向。

[快速开始](#快速开始) · [给 agent 的提示词](#给-agent-的提示词) · [浏览词库](seed.mjs) · [HTTP API](docs/api.md)

## 为什么术语能帮上忙

“高级、现代、有设计感”留下了很大的解释空间。专业术语可以把设计意图落到明确的视觉关系上，让 agent 有依据地决定网格、比例、色彩、字体和细节。

FormLex 为每个术语配上应用说明，把美术语言接到前端实现中。例如：

| 设计线索 | 可以交给 agent 的具体决策 |
| --- | --- |
| 瑞士国际主义 | 建立严谨网格、非对称编排与无衬线字体系，用对齐组织信息。 |
| 浮世绘平面性 | 用轮廓勾线、平涂色面和大胆裁切处理主视觉，形成鲜明的平面关系。 |
| 邻近色配色 | 在相邻色相中建立色板，再通过明度差区分背景、内容和强调区域。 |
| 现代衬线 Didone | 用高笔画对比的大标题建立视觉焦点，正文选择更适合阅读的字形。 |
| 透明罩染 Glazing | 叠加薄透明色层表现材料深度，让底色参与表面质感。 |
| 预备动作 Anticipation | 在主要变化前加入短暂的方向或尺度提示，让动作更容易理解。 |

这些线索提供了**可执行的约束、可组合的差异和可讨论的设计依据**。你可以明确地要求“保留编辑式排版，把材质换成暖纸”，逐步收敛到适合内容的界面。

## 为前端「去 AI 味」的工作流

1. **抽取方向**：选择需要的维度，点击“抽取一组灵感”。每个维度默认获得 2–3 条术语及说明。
2. **交给 agent**：点击“复制文本”，连同页面需求和下方提示词一起发送，让 agent 将术语落实到界面。
3. **保留与调整**：锁定喜欢的维度，只重抽需要改变的部分；根据实际页面继续调整配色、比例与细节。

FormLex 提供设计输入，页面由你使用的 agent 构建。术语组合用于启发主次和应用范围：确定一个主导方向，再让其余线索服务于局部元素，避免把所有风格平均铺满页面。

## 项目优势

- **从美术语汇中寻找差异**：400 条词条涵盖艺术流派、构成、色彩关系、排印、材料与运动规律，为界面探索提供更多选择。
- **每个词都有落地说明**：将抽象概念转化为可以用于布局、视觉或交互的建议，减少反复解释设计意图的成本。
- **随机探索，也能精确控制**：支持维度选择、固定 2 条或 3 条、整组锁定与单维重抽，保留有效方向，持续尝试新组合。
- **人和 agent 共用一份词库**：网页可直接操作，HTTP API 可供本机 agent 调用；中文文本与结构化 JSON 都能复制使用。
- **沉淀自己的设计语言**：词条、说明与互斥关系均可编辑；喜欢的组合可以收藏，最近 100 次成功抽取自动保留快照。
- **本机运行，零额外依赖**：使用 Node.js 原生 HTTP 服务与 HTML、CSS、JavaScript，无需 API Key。词库和记录保存在本机 JSON 文件中，抽取过程不调用模型。

## 给 agent 的提示词

将下面的模板与抽取结果一起发送，替换其中的项目需求即可：

```text
请为以下项目构建或重构前端：
[页面用途、目标用户、核心内容、技术栈与现有约束]

使用后面的 FormLex 设计灵感组合：
1. 根据项目内容确定一个主导设计方向，说明其余术语适合应用在哪些区域。
2. 将术语落实为布局、间距、配色、字阶、形状、材质与交互反馈的具体选择。
3. 让视觉层级围绕内容和主要操作展开，控制装饰的使用范围。
4. 同时处理窄屏布局、文字可读性、键盘操作和减少动态偏好。
5. 完成实现后，检查实际页面，并简要说明采用了哪些线索、如何落地。

设计灵感组合：
[粘贴 FormLex 复制的文本]
```

已有满意的页面时，可以只抽取色彩、排版或材质，给局部改版提供方向；搭建新页面时，则可以从完整的八维组合开始。

## 快速开始

需要 **Node.js 22 或更新版本**。

```sh
git clone https://github.com/Inderwish/formlex.git
cd formlex
node server.mjs
```

打开 <http://127.0.0.1:3000>。无需执行 `npm install`。按 Ctrl+C 停止服务。

Windows 用户也可以双击项目目录中的 **`启动灵感采样.bat`**，服务就绪后会自动打开浏览器。保留终端窗口即可持续使用，关闭窗口则停止服务。

指定端口或数据位置：

```sh
node server.mjs --port 3001
node server.mjs --data-file ./my-data/state.json
```

也支持 `PORT`、`DATA_FILE` 环境变量，命令行参数优先。服务只监听 `127.0.0.1`；不要让多个实例同时使用同一个数据文件。

## 工作台功能

| 功能 | 用法 |
| --- | --- |
| 协调模式 | 排除词库中显式配置的互斥关系，覆盖同维度与跨维度组合；任一方向声明互斥即生效。 |
| 自由模式 | 独立随机抽取，允许不同方向自由碰撞。 |
| 锁定与重抽 | 锁定会保留该维度整组词条及顺序；单维重抽保持其余结果不变。 |
| 全览与单维聚焦 | 调整查看范围，复制和收藏始终保留完整组合。 |
| 词库管理 | 按维度筛选、搜索、新增、编辑和删除词条，维护互斥关系。 |
| 复制与收藏 | 复制中文文本或 JSON；剪贴板不可用时提供手动复制文本框。 |
| 收藏与历史 | 每次打开页面会自动抽取一组；网页和 HTTP 抽取均进入历史。收藏独立保存，词条后续修改不会改变已有快照。 |

协调模式只检查显式互斥，不做模型语义判断。候选不足、锁定冲突或搜索达到上限时会提示原因并保留当前结果，可调整条件后再抽取。

## 让 agent 直接调用

启动服务后，具备本机 HTTP 访问能力的 agent 可以直接读取词库或抽取灵感。在 Windows 的 **pwsh** 中也可以调用：

```sh
curl.exe http://127.0.0.1:3000/api/catalog
curl.exe --json '{"mode":"coordinated"}' http://127.0.0.1:3000/api/draw
curl.exe --json '{"dimensions":["color","type","material"],"mode":"free","countPerDimension":2}' http://127.0.0.1:3000/api/draw
```

抽取响应包含记录 ID、时间、模式、词条及可复制文本。网页与 API 共用同一套词库、抽取规则和记录。

完整的请求参数、锁定与重抽示例、词条编辑接口及错误说明见 [HTTP API 文档](docs/api.md)。

## 数据与开发

- `seed.mjs`：400 条内置术语及维度定义。
- `public/`：网页界面；`server.mjs`：本机 HTTP 服务。
- `core.mjs`：抽取、互斥规则和本地保存逻辑。
- `data/state.json`：首次运行时创建，保存个人词库、历史和收藏。

数据文件使用 UTF-8，通过临时文件替换保存。保存失败会报告错误；遇到损坏的数据文件时保留原文件，不会重置为初始词库。关闭服务后备份整个 `data/` 目录，即可保留个人数据；该目录已加入 Git 忽略规则。

运行测试：

```sh
node --test tests.test.mjs
```

测试覆盖抽取约束、锁定重抽、输入校验、HTTP 接口、持久化、历史与收藏快照、同源限制及保存失败。测试使用临时数据，完成后关闭测试服务并清理，成功时打印 `DONE`。

术语参考：[Getty：艺术形式要素](https://www.getty.edu/education/teachers/building_lessons/formal_analysis.html)、[Adobe：字偶距、字距与行距](https://helpx.adobe.com/ca/illustrator/using/line-character-spacing.html)。词条中的前端应用说明为本项目撰写。
