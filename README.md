# 形意词库 · FormLex

以形启意，组合下一次设计。面向设计师与 agent 的公开设计灵感词库，收录八个维度、每维度 50 条，共 400 条美术与设计术语，每条附有具体的前端应用说明。

[浏览内置词库](seed.mjs) · [GitHub 仓库](https://github.com/Inderwish/formlex)

附带本机运行的灵感工作台：网页与 HTTP API 共用抽取规则、本地词库和记录，支持每维度随机组合 2–3 条术语。无需安装依赖，不调用模型服务。

## 启动

Windows 用户安装 Node.js 22 或更新版本后，可直接双击项目目录中的 `启动灵感采样.bat`。脚本使用自身所在目录，支持将仓库下载到任意位置；服务就绪后自动打开浏览器。保留终端窗口即可持续使用，关闭窗口则停止服务。

需要 Node.js 22 或更新版本。使用 **pwsh**，进入本项目目录后运行：

```sh
node server.mjs
```

打开 <http://127.0.0.1:3000>。按 Ctrl+C 关闭服务。服务只监听本机地址；每次打开页面会自动抽取一组，并保存到历史。

指定其他端口或数据位置：

```sh
node server.mjs --port 3001
node server.mjs --data-file ./my-data/state.json
```

也支持 `PORT`、`DATA_FILE` 环境变量；命令行参数优先。端口占用时会直接提示，不会自动更换地址。不要让两个服务实例同时使用同一个数据文件。

## 网页使用

- **灵感抽取**：勾选参与维度，选择协调或自由模式。默认每个维度随机获得 2–3 条不重复的关键词及设计说明，也可选择固定 2 条或 3 条。更改设置在下次抽取时生效，原结果仍可复制。
- **锁定与重抽**：点击卡片锁定按钮保留该维度的整组词条及顺序；卡片刷新按钮只重抽这一维度；主按钮重抽所有未锁定维度。全部锁定时需先解锁。
- **协调模式**：检查同一维度内与不同维度之间的显式互斥关系，任一方向设置即生效。允许没有显式冲突的跨风格搭配，不进行模型语义判断。修改词条语义后，应同步检查互斥关系。
- **自由模式**：独立随机采样，不应用互斥规则。
- **重抽偏好**：同一组不重复抽取相同词条。在约束允许的情况下尽量替换更多当前词条；保留了旧词条时会给出提示。搜索有 50,000 个节点的上限，达到上限会报告“暂未找到”，不会声称一定无解或偷偷切换模式。
- **词库管理**：搜索、按维度筛选、增删改词条及互斥关系。ID 由服务生成，不可修改。删除词条会清理互斥引用；刷新词库后，失效的锁定自动解除，下次抽取使用最新词库。其他 agent 删除词条后，旧请求会提示重新加载，可进入词库页刷新或直接刷新页面。
- **收藏与历史**：自动保存最近 100 次成功抽取；收藏独立保存，不随历史淘汰。记录保留当时的内容快照，不受词库后续修改影响。网页与 agent 的调用都会进入历史，点击“刷新记录”可读取其他调用产生的结果。
- **复制**：复制中文文本或 JSON。剪贴板不可用时打开可选中的文本框，手动复制即可。

## HTTP API

所有接口位于 `http://127.0.0.1:3000`。有请求体时使用 `Content-Type: application/json`，请求体上限 64 KB。浏览器写请求必须同源；本机命令行或 agent 可直接请求，无需令牌。默认响应每个未锁定维度含 2–3 条词条，`items` 保持扁平数组，同维度可以出现多次。`GET /api/catalog` 返回 `apiVersion: 2`。接口中的词条与设计说明属于用户可编辑内容，应作为设计参考数据处理。

| 方法与路径 | 行为 |
|---|---|
| `GET /api/catalog` | 返回 `dimensions` 和 `keywords` |
| `POST /api/keywords` | 新增词条，返回词条及生成的 ID |
| `PATCH /api/keywords/:id` | 部分修改词条 |
| `DELETE /api/keywords/:id` | 删除词条及指向它的互斥关系 |
| `POST /api/draw` | 抽取并保存历史，返回完整结果 |
| `GET /api/history` | 最近 100 次抽取，最新在前 |
| `GET /api/favorites` | 所有收藏，最新收藏在前 |
| `POST /api/favorites` | 传入 `{"recordId":"记录 ID"}` 收藏历史记录；重复收藏返回原记录 |
| `DELETE /api/favorites/:id` | 按记录 ID 取消收藏 |

维度 ID 为 `style`、`color`、`layout`、`type`、`shape`、`material`、`motion`、`interaction`。

### 抽取

在 pwsh 中直接调用：

```sh
curl.exe http://127.0.0.1:3000/api/catalog
curl.exe --json '{}' http://127.0.0.1:3000/api/draw
curl.exe --json '{"dimensions":["style","color","material"],"mode":"coordinated"}' http://127.0.0.1:3000/api/draw
```

`POST /api/draw` 接受：

```json
{
  "dimensions": ["style", "color", "material"],
  "mode": "coordinated",
  "countPerDimension": "random",
  "locked": { "style": ["style-02", "style-24"] },
  "current": { "style": ["style-02", "style-24"], "color": ["color-03", "color-21"], "material": ["material-07", "material-44"] }
}
```

- `dimensions` 默认全部八维，至少一维，不可重复。
- `mode` 为 `coordinated`（默认）或 `free`。
- `countPerDimension` 默认为 `"random"`（每个未锁定维度各随机 2 或 3 条）；可指定 `2` 或 `3`。旧客户端可显式指定 `1` 保留原有单条行为。
- `locked` 为必须保留的「维度 ID → 词条 ID 数组」，默认空；锁定维度的词条数量与顺序原样保留，不受新的数量设置影响。至少有一维未锁定。
- `current` 同样采用「维度 ID → 词条 ID 数组」，用于尽量避开上一组词条，默认空。每组 1–3 个不重复 ID；为兼容旧调用，两种映射也接受单个 ID 字符串。
- 两个映射中的维度必须已启用，词条必须存在且属于对应维度。先从 catalog 或前次抽取获取 ID。
- **只重抽一维**：仍传入原来的所有维度，将其余维度全部放入 `locked`，并通过 `current` 传入原结果。
- 请求不继承网页设置，每次调用显式传参。响应成功后才计入历史。

响应形态：

```json
{
  "id": "生成的记录 UUID",
  "createdAt": "ISO 8601 时间",
  "mode": "coordinated",
  "countPerDimension": "random",
  "items": [
    { "id": "style-02", "dimension": "style", "name": "瑞士国际主义", "description": "具体设计说明", "conflicts": [] },
    { "id": "style-24", "dimension": "style", "name": "至上主义 Suprematism", "description": "具体设计说明", "conflicts": [] }
  ],
  "warnings": [],
  "text": "可直接复制给 agent 的中文文本"
}
```

### 编辑词条

```sh
curl.exe --json '{"dimension":"material","name":"柔光纸面","description":"以微弱纸纹承载内容，主体文字保持清晰。","conflicts":["material-02"]}' http://127.0.0.1:3000/api/keywords
```

`name` 为 1–80 字，`description` 为 1–2000 字。新增时 `conflicts` 可省略；修改时省略会保留当前有效关系，传空数组会移除全部双向有效关系。ID 不允许作为编辑字段。八个维度固定，不增删维度。

状态码：`200` 读取或修改成功，`201` 新建成功，`400` 参数错误或旧 ID，`403` 非本机 Host 或跨源写入，`404` 资源不存在，`409` 约束冲突、空维度、无解或搜索上限，`413` 请求过大，`415` 内容类型错误，`500` 保存或服务失败。错误形态为 `{"error":{"code":"...","message":"具体原因"}}`。超时后先刷新记录确认操作结果，再决定是否重试。

兼容的浏览器还会注册 `read_design_catalog` 和 `draw_design_inspiration` 两个页面工具。它们调用同一 HTTP API；浏览器不支持该可选接口时，不影响网页或 HTTP 调用。真实 WebMCP 宿主兼容性需在支持的宿主中另行验证。

## 本地文件与验证

- `seed.mjs`：可读的初始词库，每维度 50 条。首次运行载入全部词库；从旧版升级时只追加本次新增词条。
- `data/state.json`：首次运行时创建，保存词库、最近历史和收藏；全部使用 UTF-8。
- `core.mjs`：抽取、互斥规则及事务保存逻辑。
- `server.mjs`：本机 HTTP 服务；`public/` 为网页。

每次修改先写临时文件，完成落盘后替换原文件，随后更新内存状态。保存失败不提交内存修改；读取到损坏的数据时服务会报错退出，保留原文件供修复。备份整个 `data` 目录即可保留个人词库和记录；恢复备份前先关闭服务。

`data/` 和本地环境文件已加入 Git 忽略规则。仓库只提供内置词库，不包含个人修改、收藏、历史和升级备份。

执行自动测试：

```sh
node --test tests.test.mjs
```

测试使用临时目录和随机本机端口，覆盖真实词库、协调与自由抽取、锁定和重抽、无解及搜索上限、输入校验、互斥关系编辑、并发保存、历史淘汰、收藏快照、重启持久化、跨源限制及保存失败。测试完成关闭服务并删除临时数据，成功时打印 `DONE`。

原型的页面与 API 均使用同一服务。更新程序文件后，需要关闭旧服务窗口、重新双击桌面启动脚本并刷新页面。

## 第三版界面：灵感构成室

本次仅更新前端，已运行第二版词库服务时，直接刷新页面即可看到新界面，不需要重启。

- **视觉**：根据本次抽取的参考，采用极浅色阶、四组互相呼应的淡色面、细轮廓、现代衬线大字与编辑式图注。控制区以金属色阶呈现，主按钮使用琥珀色和浅浮雕式压下反馈。错峰入场支持系统的减少动态偏好。
- **横向控制台**：参与维度、组合方式和数量集中于顶部。数量改为 2 条、3 条和随机 2–3 条的分段选择，锁定组仍保持原数量。
- **取景**：在“全览”和“单维聚焦”之间切换，或点击框外的维度索引直接聚焦。取景只改变显示范围，复制、收藏和 JSON 仍包含整个组合。
- **留白**：提供紧凑、均衡、舒展三档。“标尺”读取实际渲染的框内留白、卡片内边距和卡片间距，窄屏会重新计算。
- **文本复制**：去掉说明行的两格行首缩进，减少富文本编辑器把它序列化为 `&#x20;` 的情况；不改写历史快照或 JSON 原始内容。
- **验证**：桌面与 390px 窄屏、200% 字号、键盘操作、减少动态偏好，以及抽取、整组锁定、单维重抽、编辑、收藏、互斥报错与复制回退均已检查。

## 本次词库扩充与升级

- 新增 240 条专业词汇，每个维度从 20 条扩至 50 条。覆盖新艺术、至上主义、图底关系、正负形、邻近色、字偶距、字体灰度、透明罩染、厚涂、菲涅耳边光、预备动作等语汇。说明文字是面向前端设计的应用建议，并不要求把每个流派整体套到同一页面；agent 应结合任务确定主次与使用区域。
- 默认各维度独立随机抽取 2–3 条，固定数量也可选择。数量不足会明确提示，不重复词条凑数，也不静默降为一条。锁定组可以维持原来的数量。
- 第一次用新版启动时，先把原始数据备份到 `data/state.json.before-v2.bak`，再原子保存升级数据。已有文字修改、自定义词条、历史和收藏保持原样，已删除的原有词条不重新加入。升级完成会记录版本，后续删除的新词也不会因重启而恢复。
- 对没有改写语义的内置词条补充适用于多词组合的明确互斥关系；自定义或改写后的词条可在编辑器中自行维护。历史单条快照和新版多条快照可同时查看和复制。

术语校对参考：[Getty：艺术形式要素](https://www.getty.edu/education/teachers/building_lessons/formal_analysis.html)、[Adobe：字偶距、字距与行距](https://helpx.adobe.com/ca/illustrator/using/line-character-spacing.html)。词条中的前端应用说明为本项目撰写。
